维护规则

  1. 新语法、关键字、标准库 API 或命令首次进入课程正文、练习代码或可执行代码块前，先在该课程添加完整解释，再在本表添加一行。
  2. 后续课程只写解决当前问题所需的简短提醒，并链接到本表和首次说明；出现新的边界或版本差异时，更新首次说明和本表的“已说明的边界”。
  3. 本表不取代检索练习。学习者仍需能解释、预测行为或完成练习，才能把知识记录为已掌握。
