Go 的 for 与 range 速查

Go 只有一个循环关键字：for。range 是它的一种子句，用来从集合、channel、整数或迭代器中依次取值。

for 的四种常用形式

形式含义何时用
for cond {}每次先检查条件；为真才执行。等待状态变化。
for init; cond; post {}初始化一次；每轮检查；轮尾执行 post。需要计数器或步长。
for range x {}遍历 x 产生的项。大多数集合、channel、整数循环。
for {}无限循环，必须在内部退出或阻塞。服务循环、worker；要有退出机制。

range 左侧写法

for range x {}          // 不需要任何值
for v := range x {}     // 声明一个迭代变量
for k, v := range x {}  // 声明两个迭代变量（仅某些 x 支持）
for k, v = range x {}   // 使用已经存在的变量
for _, v := range x {}  // 丢弃第一个值；_ 是空标识符

:= 会声明新变量，它们的作用域是循环块；= 不声明变量，必须先有可赋值的 k、v。

不同右侧类型产生什么值？

右侧第一个值第二个值重要规则
array / slice索引 int元素副本索引递增；nil slice 零次。
string字节索引Unicode code point（rune）不是按 byte 遍历字符；无效 UTF-8 得到 U+FFFD。
mapkeyvalue 副本顺序未指定；nil map 零次。
channel收到的元素无一直收至关闭；nil channel 永久阻塞。
整数（Go 1.22+）0...n-1无n <= 0 时零次。
迭代器函数（Go 1.23+）yield 产生的值可选高级特性；当前课程暂不需要。

三个常见陷阱

  1. map 不保证顺序：不要依赖输出或处理顺序；需要排序时先收集 key 再排序。
  2. 元素值通常是副本：for _, v := range slice { v++ } 不会修改 slice；要写回使用索引 slice[i]++。
  3. range channel 等待 close：发送端不关闭 channel，接收端的循环不会自然结束。

流程控制

for i := range 10 {
	if i == 3 {
		continue // 跳过本轮其余部分，开始下一轮
	}
	if i == 7 {
		break // 退出最近的 for
	}
}

嵌套循环需要退出外层时使用 label：break Outer 或 continue Outer。label 必须贴在对应的 for 前。
